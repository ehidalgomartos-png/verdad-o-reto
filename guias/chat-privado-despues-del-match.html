RESPUESTA RÁPIDA

Por qué el chat se abre tras el interés mutuo

Separar el descubrimiento del chat reduce mensajes no solicitados. Primero cada persona decide si quiere conectar; después se crea un espacio privado para conversar.

Dentro de V/R Match ese espacio también permite proponer una partida, volver al chat cuando termina y gestionar la conexión sin abandonar la experiencia.

SEGURIDAD Y CONSENTIMIENTO

El control siempre es tuyo

V/R Match es solo para personas adultas. Puedes hablar sin jugar, detener una dinámica, eliminar un Match, bloquear o denunciar. No compartas contraseñas, códigos, datos bancarios ni una ubicación exacta.

PREGUNTAS FRECUENTES

Respuestas claras

¿Quién puede abrir el chat?

El chat se habilita automáticamente cuando existe un Match mutuo.

¿Puedo iniciar un juego desde el chat?

Sí. La invitación a Verdad o Reto se envía desde la conversación.

¿Qué ocurre si elimino el Match?

La conexión deja de estar disponible conforme a los controles de la plataforma.

¿Puedo denunciar desde la conversación?

Sí. La experiencia incluye mecanismos de denuncia y bloqueo.
