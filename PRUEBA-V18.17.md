# Prueba V18.17 — Onboarding y Activación

## Cuenta nueva
- [ ] Crear cuenta.
- [ ] Debe aparecer selección de ciudad.
- [ ] Elegir ciudad y comprobar que sube el progreso.
- [ ] Entrar en Perfil y comprobar la tarjeta de activación.
- [ ] Escribir nombre y edad: el paso de perfil básico se refleja visualmente.
- [ ] Añadir una foto: el paso Foto cambia a completado antes de guardar.
- [ ] Escribir al menos 20 caracteres de bio y 2 intereses separados por comas.
- [ ] Guardar el perfil.
- [ ] Debe aparecer el onboarding “Primeros 5 minutos”.

## Descubrir
- [ ] El coach superior muestra el siguiente paso.
- [ ] Dar el primer like.
- [ ] Tras unos instantes el coach pasa a “Consigue tu primer match”.
- [ ] Crear un match con una segunda cuenta.
- [ ] El progreso cambia a “Rompe el hielo”.
- [ ] Enviar un mensaje.
- [ ] El progreso llega al 100% y el coach desaparece.
- [ ] Probar una combinación de filtros sin resultados: debe ofrecer “Quitar filtros”.
- [ ] Probar una ciudad/zona con pocos perfiles: debe explicar que VRMatch está creciendo y ofrecer revisar radio/preferencias o invitar.

## Cuenta existente
- [ ] Iniciar sesión con una cuenta antigua.
- [ ] El progreso se calcula a partir de ciudad, perfil y actividad existentes.
- [ ] No se obliga a repetir pasos ya realizados.

## Administración
- [ ] Métricas → Embudo contiene “Perfil listo”.
- [ ] Exportar CSV.
- [ ] CSV contiene activation_percent, profile_ready y next_step.

## Regresión
- [ ] Registro/login siguen funcionando.
- [ ] Guardar perfil sigue funcionando.
- [ ] Likes y matches siguen funcionando.
- [ ] Chat sigue funcionando.
- [ ] Juegos y referidos siguen funcionando.
- [ ] /healthz muestra 18.17.0.
