FAQ

Sobre pagos y Premium

¿La aplicación seguirá siendo gratuita?

Sí. V/R Match mantendrá una modalidad gratuita.

¿Premium será obligatorio?

No. Premium será opcional y estará pensado para funciones adicionales.

¿Qué ocurre si nunca contrato Premium?

Podrás continuar utilizando la modalidad gratuita de V/R Match.

¿Qué métodos de pago habrá?

Los métodos concretos se mostrarán cuando se active la parte comercial. Ahora no es necesario introducir ningún método de pago.

¿Puedo cancelar Premium?

Cuando se lancen suscripciones, las condiciones y el proceso de cancelación se mostrarán antes de contratar.
