# Checklist de prueba — Fase 8 V/R+

## 1. Salud
- [ ] Render muestra `V/R Match v8.0`.
- [ ] `/healthz` devuelve `version: 8.0.0`.
- [ ] SMTP sigue configurado.
- [ ] Admin sigue configurado.

## 2. Free
- [ ] Una cuenta Free ve el botón V/R+.
- [ ] Rewind abre/informa sobre V/R+ y no ejecuta la acción.
- [ ] Filtros V/R+ aparecen bloqueados.
- [ ] Boost aparece bloqueado.

## 3. Conceder V/R+
- [ ] Admin → Usuarios → Revisar.
- [ ] `Conceder V/R+ 30 días` funciona.
- [ ] El historial registra la acción.
- [ ] La cuenta cambia a V/R+ sin necesidad de cambiar el código.

## 4. Rewind
- [ ] Pasar un perfil.
- [ ] Pulsar ↶.
- [ ] El último perfil pasado reaparece.
- [ ] Si no hay pass previo se muestra un aviso correcto.

## 5. Filtros avanzados
- [ ] Solo correo confirmado.
- [ ] 1, 2 y 3 intereses en común.
- [ ] Orden por compatibilidad.
- [ ] Orden por cercanía.
- [ ] Orden por intereses.
- [ ] Orden por actividad reciente.

## 6. Boost
- [ ] Activar Boost.
- [ ] Estado muestra 30 minutos.
- [ ] La cuenta priorizada aparece antes en Descubrir de otra cuenta compatible.
- [ ] No permite activar otro Boost durante el cooldown.

## 7. Revocar
- [ ] Admin puede revocar V/R+.
- [ ] Rewind vuelve a quedar bloqueado.
- [ ] Filtros avanzados quedan bloqueados.
- [ ] Boost deja de estar disponible.
- [ ] Historial registra la revocación.

## 8. Regresión
- [ ] Registro/login.
- [ ] Perfil + fotos.
- [ ] Ubicación/distancia.
- [ ] Like/match.
- [ ] Chat.
- [ ] Juego desde chat y regreso.
- [ ] Denuncia/moderación.
- [ ] Recuperación de contraseña.
