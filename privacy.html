Privacidad

Información sobre los datos que utiliza V/R Match y cómo se gestionan.

Privacidad: V/R Match utiliza únicamente los datos necesarios para prestar, proteger y mejorar el servicio, de acuerdo con las opciones disponibles en tu cuenta.

Datos de cuenta

Correo electrónico, contraseña almacenada mediante hash, estado de verificación y datos técnicos de sesión.

Perfil y actividad

Nombre, edad, identidad/género, ciudad, biografía, intereses, fotos, preferencias de descubrimiento, likes, matches, mensajes y acciones de seguridad.

Ubicación

Si das permiso, guardamos coordenadas reducidas de precisión para calcular distancias. Otros usuarios reciben una distancia aproximada, no tus coordenadas ni una dirección exacta.

Orden inteligente de Descubrir

Para ordenar los perfiles que ya cumplen tus preferencias, V/R Match puede combinar señales del propio servicio como distancia aproximada, intereses compartidos, actividad reciente, grado de completitud del perfil y estados de verificación. Este orden no intenta diagnosticar personalidad ni inferir atributos sensibles, y nunca sustituye tus filtros de edad, género, distancia, bloqueos o preferencias recíprocas. Algunas razones generales —por ejemplo, intereses en común o misma ciudad— pueden mostrarse para explicar por qué un perfil aparece antes.

Ciudad y crecimiento de comunidad

Al crear tu cuenta te pedimos una ciudad o municipio. Se utiliza para completar tu perfil, organizar el crecimiento local de VRMatch y mostrar contadores agregados de cuántas cuentas activas han elegido cada ciudad. El contador público muestra únicamente totales por ciudad, no la identidad, el correo ni la ubicación exacta de las personas incluidas. Puedes cambiar tu ciudad desde tu perfil. La ubicación aproximada para calcular distancias es una opción separada y voluntaria.

Acceso anticipado histórico

Si participaste en una lista de acceso anticipado anterior, pueden mantenerse los datos necesarios de ese registro —como alias, edad, correo, ciudad, código de invitación y estado de activación— mientras sean necesarios para gestionar la transición, atender derechos o conservar la integridad de atribuciones y seguridad. Esa información no se utiliza para bloquear el registro abierto actual.

Invitaciones entre usuarios

Las cuentas activas pueden recibir un código personal de invitación. V/R Match puede contar visitas, veces compartido y altas atribuidas a ese código para mostrar progreso de referidos y medir el crecimiento del producto. Estas métricas no muestran al usuario que invita la identidad, el correo ni el perfil de las personas registradas mediante su enlace.

Seguridad y moderación

Bloqueos, denuncias y un contexto limitado de mensajes pueden conservarse para revisión de seguridad. Las acciones administrativas quedan registradas.

Verificación opcional de perfil

Puedes solicitar voluntariamente una insignia de perfil verificado enviando una selfie actual. La selfie se guarda en un directorio privado, no aparece en tu perfil ni se entrega a otros usuarios y solo es accesible al equipo autorizado de moderación durante la revisión. La revisión es visual y manual; no utilizamos reconocimiento facial biométrico. La prueba se elimina automáticamente cuando la solicitud se aprueba o se rechaza. Conservamos únicamente el estado de la revisión, fechas y, cuando exista, una nota de moderación.

Prevención de abuso

V/R Match aplica límites de uso y puede registrar señales técnicas de seguridad —por ejemplo, ráfagas anómalas de likes o envío repetitivo del mismo mensaje a numerosos matches— para prevenir spam y priorizar revisiones. Estas señales no producen una sanción automática por sí solas y no almacenan una copia adicional del contenido de tus chats.

Avisos y recordatorios por correo

Si mantienes activadas las preferencias correspondientes, V/R Match puede enviarte correos de servicio sobre un nuevo match y recordatorios de retención como perfil incompleto, un nuevo mensaje cuando no estás conectado, una invitación a jugar o un match que todavía no ha iniciado conversación. Los correos no incluyen el contenido privado de los chats. Los recordatorios de retención solo se envían a cuentas con correo verificado, aplican límites de frecuencia y pueden desactivarse desde el centro de notificaciones mediante “Recordatorios por email”.

Proveedores

V/R Match utiliza Render para alojamiento y Resend/SMTP para el envío de correos. Otros servicios técnicos podrán incorporarse cuando sean necesarios para prestar o proteger la plataforma.

Control de la cuenta

Puedes pausar tu perfil, controlar visibilidad, estado online e invitaciones, cambiar contraseña, bloquear, denunciar, descargar tus datos y eliminar tu cuenta desde la app.

Partidas y respuestas sincronizadas

Las respuestas, elecciones y predicciones utilizadas durante las partidas se procesan para sincronizar el juego en tiempo real. Las respuestas secretas de las rondas compartidas no se guardan como historial persistente de partida. Las fotos y vídeos enviados como prueba tampoco se incorporan al historial del chat.

Historial de partidas

Para mostrar cuántas veces habéis jugado y medir el funcionamiento del producto, V/R Match puede conservar datos agregados de una partida: Match asociado, mazo, fecha, duración, rondas completadas, rondas sincronizadas, coincidencias, aciertos, reacciones y si hubo rondas extra. Este historial no guarda el texto de las respuestas, el contenido de las cartas, fotos ni vídeos de las pruebas.

Analítica propia y mejora del producto

V/R Match puede registrar métricas propias de primera parte para entender el funcionamiento del servicio y su crecimiento: sesiones de visita, página de entrada, parámetros de campaña UTM (fuente, medio, campaña y contenido), registro, selección de ciudad, creación de perfil y acciones agregadas como likes, matches, mensajes, partidas o compartidos. Esta analítica no guarda el contenido de los chats, las respuestas privadas de las partidas, coordenadas ni una huella digital del dispositivo. Antes de iniciar sesión se utiliza un identificador aleatorio limitado a la pestaña/sesión del navegador para relacionar una visita con un posible registro en esa misma sesión. La aplicación también calcula un progreso de activación usando esas acciones ya existentes —por ejemplo, ciudad elegida, perfil creado, foto, intereses, primer like, primer match y primer mensaje— para guiarte durante los primeros pasos y para analizar de forma agregada dónde se abandona el proceso. También pueden recopilarse diagnósticos de errores para mejorar la estabilidad, la seguridad y la experiencia de uso. Los diagnósticos técnicos del servidor pueden incluir fecha, tipo de error, ruta y un identificador de petición; no guardamos mediante este registro el body de la petición, contraseñas, tokens, cookies ni contenido de chats. También puedes enviar comentarios voluntariamente desde la aplicación.
